Setup

Two switches, asked once — then the button says what happened

Each permission row reads Allow while the switch is off and Allowed once it is on, so the button never asks for something it already has. The ask happens as the app opens, and the same sheet sets up the keyboard key.
On open. Both switches ship off, so the app asks before anything else — one sheet, one tap through to Android for each.
After the first. The sheet keeps up as you come back: the granted row leaves, the count drops to one.
Ready. Both rows read Allowed, the sheet closes itself, and the whole page sits on one screen — no scrolling.
